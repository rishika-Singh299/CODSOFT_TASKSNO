# Task 2 - Tic-Tac-Toe AI

## Description

This project is a Tic-Tac-Toe game developed using Python as part of the CODSOFT Artificial Intelligence Internship.

The game allows a human player to play against an AI opponent. The AI uses the **Minimax algorithm** to select the best possible move.

## Features

- Human vs AI gameplay
- 3 × 3 Tic-Tac-Toe board
- Player uses **X**
- AI uses **O**
- AI uses the Minimax algorithm
- Checks for winning combinations
- Detects draws
- Prevents invalid moves
- Simple command-line interface

## Technologies Used

- Python
- Minimax Algorithm
- Game Theory
- Artificial Intelligence
- Conditional Statements
- Functions
- User Input

## How It Works

The player makes the first move using **X**.

After every player move, the AI evaluates the available moves using the **Minimax algorithm** and selects the move with the best possible outcome.

The game continues until:

- The player wins
- The AI wins
- The game ends in a draw
