
# Task 4 - Recommendation System

## Description

This project is a simple Movie Recommendation System developed using Python as part of the CODSOFT Artificial Intelligence Internship.

The system recommends movies based on the user's preferred movie genre.

## Features

- Takes user's preferred genre as input
- Searches movies based on genre
- Recommends matching movies
- Handles genres with no available recommendations
- Simple command-line interface

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- String Processing
- Conditional Statements

## How It Works

The system contains a predefined list of movies along with their genres.
