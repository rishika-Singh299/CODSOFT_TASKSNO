# Task 1: Rule-Based Chatbot

## Description
A simple rule-based chatbot developed using Python that responds to user inputs with predefined messages based on keywords. This chatbot is created as Task 1 of the CODSOFT AI Internship.

## Features
- ✅ Responds to greetings (hello, hi, hey, hii)
- ✅ Answers "How are you?" questions
- ✅ Provides information about itself
- ✅ Offers help when asked
- ✅ Explains the internship task
- ✅ Thanks the user
- ✅ Graceful exit commands (bye, goodbye, exit, quit)
- ✅ Handles unknown queries gracefully

## Requirements
- Python 3.x
- No external libraries required

## Installation
1. Clone the repository:
```bash
   git clone https://github.com/rishika-Singh299/CODSOFT_TASKSNO.git
```

2. Navigate to Task 1 folder:
```bash
   cd CODSOFT_TASKSNO/Task1_RuleBasedChatbot
```

## How to Run
Run the chatbot using Python:
```bash
python chatbot.py
```
